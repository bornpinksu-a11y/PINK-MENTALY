PINK MENTALY — sitio web
========================
Abre  public.html  (o index.html) en tu navegador.

Estructura
  *.html                páginas sueltas (public, avatar, ropa, tienda, carrito, login, cuenta...)
  public/css/style.css  todo el diseño y las animaciones
  public/js/            toda la lógica (avatar, catálogo, carrito, cuentas, efectos)
  public/img/logo.png   logo con fondo transparente

Para editar productos y precios:  public/js/catalogo.js
Para cambiar datos de contacto:   contacto.html (están marcados como ejemplo)

Importante: el carrito, las cuentas y los pedidos funcionan en el navegador (demo).
Para vender de verdad necesitas un servidor y una pasarela de pago.
